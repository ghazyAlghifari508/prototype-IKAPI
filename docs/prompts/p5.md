## 17. ERROR FIXING PROCEDURE

For each defect:

1. Reproduce it.
2. Collect browser console/network/server evidence.
3. Identify the root cause.
4. Identify affected files and data flow.
5. Apply the smallest correct fix.
6. Rerun the failing scenario.
7. Rerun relevant regression checks.
8. Confirm the result.

Do not:

- Hide the error.
- Disable validation.
- Fake successful responses.
- Manipulate the database to bypass authorization.
- Replace real data with hardcoded values.
- Remove features to make tests pass.
- Introduce large unrelated refactors.

If test tooling is unavailable, report exactly which checks could not be performed.
