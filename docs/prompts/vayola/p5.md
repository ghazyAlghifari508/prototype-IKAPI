Verifikasi:

- Tombol Baca menuju route yang benar.
- Reader memverifikasi entitlement server-side.
- Original PDF tidak terekspos.
- Derived page dapat ditampilkan.
- Progress tersimpan.
- Auto-resume benar.
- Bookmark tidak mengubah progress saat hanya ditambahkan.
- Navigasi bookmark menuju halaman yang tepat.
- User A tidak dapat melihat resource Reader B tanpa entitlement sendiri.
- Suspended account mengikuti policy.

## Regression cases

Pastikan:

- Pending order tidak membuka buku.
- Expired order tidak membuka buku.
- Failed payment tidak membuka buku.
- Repeated webhook tidak membuat entitlement ganda.
- File PDF baru tidak menampilkan halaman lama secara salah.
- Invalid page tidak membocorkan private file.
- Reader error tidak berubah menjadi link download original.

Jika modul Ghazy/Devina belum tersedia, tandai pengujian lintas modul sebagai **Blocked**, bukan Pass.
