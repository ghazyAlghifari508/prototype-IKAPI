# 13. Perbaikan Status Tandai Selesai

## Bug yang ditemukan

Fungsi:

`markAsFinished()`

Saat ini melakukan perubahan:

`card1.dataset.status = 'unread'`

Padahal tindakan pengguna adalah menandai buku sudah selesai.

Ini harus diperbaiki.

## Perilaku benar

Gunakan status selesai, misalnya:

`completed`

Ketika pengguna menandai buku selesai:

- Buku tidak lagi dianggap Sedang Dibaca.
- Buku tidak berubah menjadi Belum Dibaca.
- Buku tetap muncul di Semua Buku.
- Progress menjadi selesai jika memang itu konsekuensi fitur.
- Banner Lanjutkan Membaca harus diperbarui atau disembunyikan jika tidak ada buku aktif.
- Tab dan jumlah buku diperbarui.
- Favorit tidak berubah.
- State buku tetap konsisten selama sesi prototype.

Jangan hanya menampilkan toast sukses.

# 14. Perbaikan Sorting

## Masalah

Fungsi:

`applySorting()`

Sekarang hanya memanggil toast.

Urutan card tidak berubah.

## Perubahan wajib

Sorting harus benar-benar mengubah urutan buku.

Pertahankan opsi:

- Terakhir Diakses.
- Judul (A-Z).
- Kemajuan Baca.

### Aturan

**Terakhir Diakses**

Urutkan berdasarkan timestamp terakhir membaca jika data tersedia.

Untuk prototype, gunakan data contoh yang konsisten.

Jangan mengarang aktivitas membaca baru setiap kali halaman dimuat.

**Judul (A-Z)**

Urutkan secara alfabetis menggunakan judul buku.

**Kemajuan Baca**

Urutkan berdasarkan progress membaca.

Tentukan arah pengurutan yang konsisten, misalnya progress tertinggi lebih dulu.

### Kriteria

- Urutan card benar-benar berubah.
- Sorting bekerja pada tab aktif.
- Sorting tetap bekerja ketika search aktif.
- Sorting tidak mengubah jumlah buku.
- Sorting tidak mengubah status favorit.
- Grid/list view tetap mengikuti urutan yang sama.

Jangan menampilkan toast "berhasil diurutkan" jika urutan tidak berubah karena fungsi belum diimplementasikan.

# 20. Scrolling Wajib Berfungsi

HTML saat ini mempunyai aturan global:

`::-webkit-scrollbar { display: none; }`

Periksa dan hapus penyembunyian scrollbar global jika tidak diperlukan.

Jangan menganggap aturan tersebut otomatis menonaktifkan scroll, tetapi pastikan scroll dapat digunakan secara normal.

### Wajib diuji

- Mouse wheel.
- Touchpad.
- Keyboard.
- Swipe mobile.
- Scroll sampai footer.
- Scroll pada mode grid.
- Scroll pada mode list.
- Scroll pada empty state.
- Scroll setelah simulasi dipulihkan.

Jangan memakai root `overflow: hidden` yang mengunci halaman.

Jangan memotong konten karena fixed viewport height.

Jangan menambahkan custom nested scrolling untuk seluruh perpustakaan.
