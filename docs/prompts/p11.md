# 7. Perbaikan Kalender Interaktif

\*\*Ini prioritas fungsional tertinggi.\*\*

## Masalah kode saat ini

### A. Filter tanggal tidak benar-benar memfilter event

Pada \`selectDate(day)\`, kode hanya menampilkan atau menyembunyikan seluruh \`events-container\`.

Contohnya:
- Klik 18 November.
- Heading berubah menjadi satu kegiatan.
- Namun tiga card masih tampil.

Ini salah.

### B. Tanggal 14 tidak konsisten

Kalender menandai 14 November sebagai tanggal yang memiliki acara.

Namun daftar kegiatan yang terlihat hanya menampilkan acara 18, 22, dan 28 November, selain featured event 18–20 November.

Jangan membuat indikator acara pada tanggal yang tidak memiliki data event.

### C. Pergantian bulan hanya mengubah label

\`prevCalendarMonth()\` dan \`nextCalendarMonth()\` hanya mengganti teks bulan.

Grid tanggal dan data event tidak diperbarui.

### D. Tampilkan Semua salah perilaku

Tombol "Tampilkan Semua" memanggil \`selectDate(18)\`.

Seharusnya tombol tersebut menghapus filter tanggal dan kembali menampilkan seluruh agenda pada bulan aktif.

### E. Label Hari Ini salah

Pada simulasi 18 November, HTML menggunakan:

"Agenda Hari Ini: 18 November 2026"

Tanggal 18 November bukan selalu hari ini.

Gunakan:

\*\*Agenda 18 November 2026\*\*

Jangan hardcode "hari ini" pada data simulasi.

## Implementasi yang diharapkan

Gunakan satu sumber data kegiatan.

Setiap event minimal mempunyai:

\`\`\`js
{
  id: "event-001",
  title: "Judul Kegiatan",
  startAt: "2026-11-18T10:00:00+07:00",
  endAt: "2026-11-18T12:30:00+07:00",
  location: "Lokasi Kegiatan",
  organizer: "Penyelenggara",
  image: "path/to/event-image.jpg",
  detailPath: null
}
\`\`\`

Ini contoh struktur data, bukan instruksi mengganti seluruh dataset dengan nilai tersebut.

Pertahankan data contoh yang sudah ada dan migrasikan secara konsisten.

Untuk acara multi-hari seperti 18–20 November, gunakan rentang tanggal yang benar.

### State kalender

Minimal:

- \`visibleMonth\`
- \`visibleYear\`
- \`selectedDate\`
- \`events\`
- \`demoMode\`

Jangan mencampurkan bulan aktif dengan tanggal pilihan.

### Perilaku yang wajib

\*\*Saat halaman dibuka:\*\*
- Kalender menampilkan November 2026 sesuai dataset prototype.
- Daftar menampilkan semua agenda bulan aktif.
- Tidak ada tanggal yang terlihat aktif jika daftar sedang menampilkan seluruh bulan.
- Tanggal yang memiliki kegiatan diberi penanda secara konsisten.

\*\*Saat memilih 18 November:\*\*
- Tampilkan kegiatan yang berlangsung pada 18 November.
- Jika featured event multi-hari relevan, pastikan logika dataset menanganinya.
- Jangan menampilkan event tanggal 22 atau 28 sebagai hasil filter tanggal 18.
- Jumlah kegiatan dihitung otomatis.

\*\*Saat memilih tanggal kosong:\*\*
- Daftar event diganti empty state.
- Kalender tetap terlihat.
- Tanggal pilihan tetap aktif.
- Tidak perlu menghilangkan seluruh section.

\*\*Saat pindah bulan:\*\*
- Label bulan berubah.
- Susunan hari berubah.
- Jumlah tanggal sesuai bulan.
- Penanda event diperbarui.
- Daftar event mengikuti bulan aktif.
- Tanggal pilihan sebelumnya dibersihkan atau dipertahankan hanya jika masih valid sesuai desain yang dipilih.

\*\*Saat menekan Tampilkan Semua:\*\*
- Hapus filter tanggal.
- Tampilkan seluruh event pada bulan aktif.
- Perbarui heading dan jumlah kegiatan.
- Jangan otomatis memilih tanggal 18.

### Perbaikan teknis

Jangan bergantung pada global \`event.currentTarget\` dalam JavaScript.

Gunakan event listener yang eksplisit atau terima elemen target melalui parameter yang benar.

Jangan hardcode 30 atau 31 tombol tanggal secara manual untuk setiap bulan.

Bangun grid kalender berdasarkan data tanggal menggunakan JavaScript.

Gunakan perhitungan tanggal yang benar, bukan sekadar toggle nama bulan.

Pastikan pergantian Desember ke Januari memperbarui tahun.

### Aksesibilitas kalender

- Setiap tanggal merupakan tombol.
- Tanggal terpilih memiliki state aksesibel.
- Tombol bulan sebelumnya/berikutnya memiliki accessible label.
- Focus state terlihat.
- Navigasi keyboard tetap berfungsi.
- Jangan mengandalkan warna atau titik saja untuk menyampaikan informasi.
