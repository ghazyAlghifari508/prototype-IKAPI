# TASK: Redesign Halaman Registrasi IKAPI Store — Konsistensi dengan Login, Ilustrasi Lokal, dan Penyederhanaan UI

## 1. Konteks dan Tujuan

Perbaiki halaman registrasi pada file:

`daftar_akun_register_desktop.html`

Gunakan sebagai referensi:

- `masuk_login_desktop.html`, khususnya versi terbaru setelah redesign panel ilustrasi.
- Screenshot halaman registrasi yang diberikan pengguna.
- Aset ilustrasi yang sudah tersedia di repository.
- Prinsip desain IKAPI yang telah disepakati pada perbaikan halaman sebelumnya.

**Tujuan utama:** membuat halaman registrasi yang konsisten dengan halaman login, menggunakan ilustrasi asli dari repository, tanpa banner promosi generik, dekorasi berlebihan, atau copy yang tidak membantu proses pendaftaran.

Pekerjaan ini bukan redesign seluruh sistem autentikasi.

Prioritas:

1. Mengganti panel kiri dengan ilustrasi lokal IKAPI.
2. Menghapus headline promosi, deskripsi panjang, badge, dan card dekoratif.
3. Menyamakan komposisi layout dengan halaman login terbaru.
4. Memperbaiki beberapa copy registrasi agar lebih singkat dan natural.
5. Mempertahankan seluruh field dan perilaku form yang sudah tersedia.
6. Memastikan layout responsif dan halaman dapat di-scroll secara normal.

Jangan membuat ilustrasi baru dari nol jika aset yang sudah tersedia memadai.

# 10. Scrolling Wajib Berfungsi

Halaman harus dapat di-scroll secara vertikal jika tinggi form lebih besar daripada viewport.

Periksa terutama pada laptop dengan tinggi layar terbatas dan mobile.

### Persyaratan

- Mouse wheel berfungsi.
- Touchpad berfungsi.
- Swipe vertikal mobile berfungsi.
- Keyboard scrolling berfungsi.
- Tidak ada fixed-height container yang memotong form.
- Tidak ada `overflow: hidden` pada root yang mengunci scroll.
- Scrollbar tidak disembunyikan secara global tanpa alasan.
- Keyboard virtual mobile tidak membuat field terakhir tidak dapat dijangkau.
- Tombol Daftar dan Lanjutkan dengan Google selalu bisa dicapai dengan scrolling normal.

HTML sebelumnya memiliki aturan:

`::-webkit-scrollbar { display: none; }`

Periksa dan hilangkan aturan global tersebut jika masih digunakan, agar scrollbar dapat terlihat secara normal.

Jangan menggunakan nested scrolling untuk seluruh form.

Gunakan scrolling browser secara natural.
