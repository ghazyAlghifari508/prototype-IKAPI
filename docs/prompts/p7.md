# 4. Ilustrasi IKAPI Wajib Benar-benar Digunakan

Repository:

`ghazyAlghifari508/prototype-IKAPI`

Branch:

`feature/breeze-auth-scaffold`

Aset:

`docs/design/assets/ilustration/auth_login_welcome.svg`

Alternatif:

### Instruksi

1. Buka dan render SVG asli.
2. Periksa aspect ratio dan transparansinya.
3. Gunakan SVG sebagai ilustrasi utama panel kiri.
4. Gunakan PNG hanya jika SVG mengalami masalah render.
5. Pastikan aset dapat dimuat dari lokasi HTML yang sebenarnya.
6. Periksa apakah browser menghasilkan request gambar yang berhasil.
7. Jangan menggunakan path yang hanya bekerja dari root repository tetapi rusak saat membuka prototype.

**Ilustrasi harus terlihat secara nyata pada screenshot akhir.**

Tidak cukup hanya menambahkan tag `<img>` ke HTML jika gambar tidak tampil.

### Tampilan ilustrasi

- Berukuran besar dan mudah dikenali.
- Menjadi fokus visual panel kiri.
- Tidak terpotong.
- Tidak terdistorsi.
- Menggunakan aspect ratio asli.
- Memiliki padding yang sesuai dengan bentuk ilustrasi.
- Tidak berada di dalam card putih tambahan.
- Tidak diberi overlay.
- Tidak diberi drop shadow berlebihan.
- Tidak diberi gradient.
- Tidak diberi label dekoratif.

Jika background SVG transparan, pilih warna panel berdasarkan palet ilustrasi sebenarnya.

Jangan asal memakai ungu neon.

### Larangan

Jangan mengganti ilustrasi dengan:

- Ikon gembok kecil.
- Ikon email besar dalam lingkaran.
- Material Symbols.
- Emoji.
- CSS shapes.
- Random SVG icons.
- Ilustrasi 3D acak.
- Screenshot website.
- Placeholder berbentuk card.

Jika aset tidak dapat dimuat, telusuri dan perbaiki sumber masalahnya. Jangan diam-diam menggantinya dengan ikon.

# 9. QA Visual Wajib — Jangan Menganggap HTML Berhasil Berarti Desain Berhasil

Ini merupakan bagian paling penting untuk mencegah pengulangan kegagalan sebelumnya.

Setelah implementasi, **buka halaman sebenarnya di browser** jika lingkungan browser tersedia.

Ambil screenshot desktop dan mobile.

### Pemeriksaan desktop

Gunakan viewport sekitar 1440 × 900 dan 1280 × 720.

Verifikasi:

1. Apakah layout benar-benar dua kolom?
2. Apakah ilustrasi IKAPI terlihat jelas?
3. Apakah ilustrasi berukuran cukup besar?
4. Apakah form berada di kanan?
5. Apakah background dotted pattern sudah hilang?
6. Apakah ikon gembok 3D sudah hilang?
7. Apakah ruang kosong terlihat seimbang?
8. Apakah kedua kolom menyatu secara visual?
9. Apakah form tetap mudah dibaca?
10. Apakah hasil berbeda secara substantif dari screenshot gagal sebelumnya?

### Pemeriksaan mobile

Gunakan viewport sekitar 390px dan 320px.

Verifikasi:

- Ilustrasi tidak terpotong.
- Form tidak terdorong terlalu jauh.
- Input dan tombol terlihat.
- Tidak ada horizontal overflow.
- Scrolling normal.
- Navigasi kembali dapat digunakan.

### Kriteria penolakan otomatis

**JANGAN menandai task selesai jika salah satu kondisi berikut masih terjadi:**

- Layout masih centered card satu kolom pada desktop.
- Tidak ada ilustrasi utama.
- Ilustrasi hanya berupa ikon kecil.
- Background masih menggunakan pola titik-titik.
- Masih ada gembok 3D dekoratif.
- Ilustrasi ditempatkan di atas heading dalam card lama.
- Kolom kiri kosong.
- Form terpotong.
- Desain menjadi dua card terpisah tanpa hubungan visual.
- Hasil kembali menyerupai template autentikasi generik yang hanya dihias.
- Agent tidak dapat membuktikan perubahan melalui render aktual tetapi mengklaim visual QA lulus.

Jika masih gagal, perbaiki layout yang menjadi penyebabnya lalu ulangi pemeriksaan.
