Nama dapat berubah; gunakan source terkini. **Jangan menganggap source di percakapan lama pasti terbaru.**

## 2. Halaman Blade independen

Usulan:

```
buyer/community/index.blade.php        # direktori, hero, filter
buyer/community/show.blade.php         # profil, join/leave, discussion preview
buyer/community/discussion.blade.php   # daftar topik, sort, buat topik
buyer/community/topic.blade.php        # detail topik, root replies + tree
buyer/community/reply.blade.php        # selected parent + composer child reply
```

Gunakan named routes dengan community/topic/reply ID yang benar, halaman bisa dibuka langsung/refresh/bookmark/Back, ID invalid → unavailable, bukan fallback ke contoh pertama. Shared header/footer berasal dari P04, bukan copy dari HTML asal.

## 3. Visual locked

- Halaman direktori **mempertahankan hero dengan ilustrasi lima orang membaca** (`docs/design/assets/ilustration/komunitasil.png` atau path aktual), heading, layout teks kiri/gambar kanan, white background. Hero hanya pada direktori.
- Community card tetap **horizontal photo-first**, grid desktop sesuai referensi, image kontekstual, tidak dibuat monogram raksasa, gradient, badge palsu.
- Profil komunitas: informasi/fokus/lokasi/membership actions dan Diskusi Terbaru sesuai source.
- Ruang Diskusi: heading, sort tabs, create-topic disabled UI, topic preview.
- Topic/Replies: hierarchy dengan avatar-aligned thin connector; root, child, sibling dan deleted-parent tidak berantakan. Hindari `border-left` yang hanya indented secara semu; validasi geometri pada kasus variatif.
- Balas Komentar: view/halaman tersendiri menunjukkan komentar target dan composer khusus; bukan scroll ke root composer.

## 4. Interaksi locked

- Guests/non-members boleh membaca public discussion tetapi tidak menulis; **Buat Topik native disabled** abu-abu bila nonmember, ungu aktif saat joined. Tidak redirect tersembunyi/auto-login/auto-join saat klik disabled.
- `Buat Topik` membuka composer topik berisi judul + isi. `Balas Topik` membuat root reply dengan `parentReplyId = null`. `Balas Komentar` membuka halaman reply dengan `parentReplyId = ID target` yang benar.
- Teks judul preview tidak memiliki invisible click-target; kontrol **ikon chat +** `N balasan` satu link yang jelas, termasuk `0 balasan`, menuju Detail Topik **tanpa auto-focus composer**. Jumlah balasan memakai satu source of truth termasuk nested active replies.
- Reply tree harus menyimpan relasi, tidak sekadar indentasi visual. Sibling terpisah dari anak. Deep nesting tetap terbaca pada mobile. Preserve edit/delete/report permissions dan deleted-parent placeholder.
- Join/Leave community, mode demo, sorting, empty/no-result states, topic edit/delete, laporan reply ke Admin. Semua disimpan di demo state yang disepakati P03/P10. Jangan invent API.
- **Ajukan Kerja Sama Komunitas dibatalkan; jangan dihidupkan lagi.** Agenda Literasi tidak dimasukkan ke Komunitas.

## 5. Data &amp; compatibility

- Pertahankan/migrasikan secara aman existing keys seperti `ikapi_community_memberships_demo`, `ikapi_community_topics_demo`, `ikapi_community_replies_demo`, `ikapi_discussion_reports_demo` setelah memverifikasi names asli.
- `topicId`, `communityId`, `replyId`, `parentReplyId`, author ownership, timestamps dan removed/edit status harus konsisten. Old replies tanpa parent dianggap root, jangan hapus ID/data.
- Detect missing/cyclic/cross-topic parents, jangan infinite recursion atau mengalihkan ke komentar lain. Penghapusan parent tidak secara tidak sengaja menghapus balasan anak.
- Baca data Admin dalam fase 9 nanti dari kontrak state yang sama, bukan fixture duplikat.

## 6. Focused tests

Scenario paths:

1. Directory search/filter → profile → join → room → topic → root reply → child reply → nested visual → refresh.
2. Nonmember sees disabled Buat Topik; guest reads topic; member can create; after leave disabled again.
3. Preview `0/1/N balasan` link opens topic from top with no composer focus.
4. Reply to different parents correctly; multi-sibling lines, &gt;3 levels, mobile 320/390.
5. Edit/delete/report nested child; deleted parent with live children; invalid ID.
6. Admin moderation fixture can read reports in P09.  
Take HTML/Blade screenshots in reference states; compare image geometry, spacing, scroll, text. Fix divergences before P08; P11 does global regression.
