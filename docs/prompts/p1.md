# PROMPT — COMPLETE LARAVEL BREEZE REMOVAL &amp; CLEANUP

## IKAPI Store Jawa Barat — Frontend-Only Blade Preparation

### ROLE

Bertindak sebagai Senior Laravel Engineer, Software Architect, dan Codebase Maintainer.

Tugasmu adalah **menghapus Laravel Breeze secara total dari aplikasi IKAPI Store**, termasuk package, seluruh scaffold yang dihasilkan, routes, controllers, requests, Blade views, reusable components eksklusif, tests, dan referensi aktifnya.

Ini adalah pekerjaan **dependency removal dan codebase cleanup**, bukan migrasi HTML ke Blade.

Repository:

[https://github.com/ghazyAlghifari508/prototype-IKAPI](https://github.com/ghazyAlghifari508/prototype-IKAPI)

Target branch:

`feature/breeze-auth-scaffold`

## 1. PROJECT CONTEXT

IKAPI Store Jawa Barat menggunakan:

- Laravel 13.
- PHP 8.4.
- Blade.
- Tailwind CSS 4.
- Vite 6.
- Alpine.js.

Saat ini repository sudah memiliki Laravel Breeze yang sebelumnya digunakan sebagai authentication scaffolding.

Namun, keputusan terbaru pemilik proyek adalah:

**Menghapus Breeze terlebih dahulu sebelum mengonversi seluruh prototype HTML menjadi Laravel Blade.**

Alasannya:

1. Halaman Login/Register IKAPI sudah mempunyai desain sendiri.
2. Dashboard Pembeli, Penerbit, dan Administrator juga sudah dirancang sendiri.
3. Layout dan komponen UI bawaan Breeze tidak diperlukan.
4. Tahap pengembangan berikutnya masih frontend-only.
5. Belum ada implementasi autentikasi Laravel sungguhan.
6. Belum ada integrasi backend bisnis.
7. Belum ada integrasi database.
8. Seluruh data dan interaksi masih menggunakan dummy data/simulasi frontend.

Breeze tidak diperlukan untuk menjalankan Blade.

### FINAL GOAL

Setelah task selesai:

**Laravel tetap berjalan normal, tetapi seluruh implementasi Laravel Breeze yang spesifik terhadap scaffold lama telah dihapus.**

Repository harus siap digunakan untuk migrasi prototype HTML ke Blade tanpa konflik halaman Login/Register, Dashboard, Profile, atau layout bawaan Breeze.
