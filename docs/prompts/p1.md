# TASK: Redesign IKAPI Store Prototype — Eliminate Generic AI-Generated UI Patterns

## 1. Context &amp; Objective

You are working on an existing IKAPI Store website prototype through FigCraft MCP.

The current prototype has serious visual quality problems. Although its information architecture is reasonably complete, the design looks like a generic AI-generated SaaS dashboard rather than a modern digital bookstore.

The user has supplied four screenshots:

- Screenshots 1–3: Existing IKAPI Store prototype that needs improvement.
- Screenshot 4: Visual reference representing the desired bookstore design direction.

**Your job is to improve the EXISTING prototype while preserving its intended features, content structure, and functional requirements.**

Do not rebuild the project from scratch unless a specific existing design element genuinely requires reconstruction.

The design should feel like a professionally art-directed, visually engaging digital bookstore suitable for Indonesian users, including Gen Z.

Primary design direction:

**Modern Editorial Bookstore + Contemporary E-commerce + Professional IKAPI Brand Identity.**

The goal is not to make everything colorful, rounded, or decorative. The goal is to produce intentional, coherent, polished design decisions.

## 2. NON-NEGOTIABLE: Eliminate AI-Slop Badges, Pills, Dots, and Decorative Labels

This is one of the user's strongest preferences.

The current prototype contains excessive decorative badges, pills, emoji, small colored labels, and generic AI-generated design ornaments.

Examples that MUST be removed or redesigned:

- `✨ PLATFORM RESMI PENERBIT SE-JAWA BARAT`
- `🔥 Paling Populer`
- `TEKNOLOGI E-READER IKAPI`
- `INTEGRASI PAYMENT GATEWAY MIDTRANS`
- `SASTRA KLASIK` and other unnecessarily colorful category labels above book titles.
- Colorful event badges such as `PAMERAN BUKU`, `WEBINAR & WORKSHOP`, and `BERITA LITERASI`.
- Decorative sparkles and emoji in the top announcement bar.
- Any colored pill, glowing indicator, or dot added only to make a section appear visually interesting.

### 2.1 What is prohibited

DO NOT:

1. Add decorative badges above every section heading.
2. Use blue, purple, orange, or green pills merely to distinguish content blocks.
3. Add sparkles, fire emoji, rockets, lightning bolts, or other emoji for marketing decoration.
4. Use tiny colored dots as unnecessary visual accents.
5. Create translucent glassmorphism badges with blur, gradient, or glow.
6. Add uppercase micro-labels everywhere to simulate a premium design.
7. Repeat the pattern `small pill → large headline → description → button` across different sections.
8. Use colorful badges as a substitute for proper typography, spacing, composition, and imagery.
9. Replace removed badges with equally unnecessary decorative lines, dots, separators, floating icons, or tiny uppercase text.
10. Reintroduce these patterns in new sections without a clear functional reason.

**Important: Removing the badge container while keeping the same decorative micro-label is NOT a valid solution.**

Example of an unacceptable change:

Before:  
`[✨ PLATFORM RESMI PENERBIT SE-JAWA BARAT]`

After:  
`PLATFORM RESMI PENERBIT SE-JAWA BARAT`

If the label contributes no necessary information, remove it entirely rather than changing its visual style.

### 2.2 What remains acceptable

Do not interpret this policy as a blanket ban on all rounded shapes or meaningful interface indicators.

The following are allowed when functionally justified:

- Cart item counts.
- Actual order or payment status.
- Verified stock availability indicators.
- Genuine discount labels supported by product data.
- User-selected filters and filter chips when necessary.
- Input controls and functional navigation elements.
- Real product ratings, when backed by actual data.

Even these elements should use restrained, consistent styling.

**The rule is simple: UI indicators must communicate meaningful information or interaction state, not serve as random decoration.**

## 5. Visual Design System

Establish a coherent visual system based on the reference and the IKAPI Store identity.

### Colors

Use a restrained palette.

Potential direction:

- Teal as a distinctive marketplace accent.
- Deep navy for brand credibility.
- White and soft neutral backgrounds.
- Carefully selected warm accents.
- Natural colors from actual book artwork.

These are suggestions, not mandatory brand colors. Respect official IKAPI brand assets and guidelines when available.

Avoid random gradients, translucent colored badges, excessive blue action buttons, and unnecessary color variation.

### Typography

Use a coherent type scale and strong hierarchy.

Potential typefaces:

- Plus Jakarta Sans.
- Inter.

Select based on the project design system and available fonts.

Avoid tiny decorative uppercase text, excessively bold headings everywhere, and overly dense supporting information.

### Cards &amp; Containers

Do not use cards as the default building block for everything.

Use cards only when the content genuinely benefits from being grouped inside a distinct surface.

Explore:

- Open layouts.
- Editorial grids.
- Image-led product tiles.
- Horizontal collections.
- Full-bleed visual sections.
- Restrained bordered containers when needed.

Never solve visual emptiness by adding arbitrary rounded boxes, shadows, or floating labels.

### Spacing &amp; Composition

Establish consistent spacing and layout grids.

Ensure:

- Clear section boundaries.
- Balanced whitespace.
- Consistent alignment.
- Logical visual rhythm.
- Appropriate content density.
- No oversized empty containers.
- No overcrowded metadata.

### Icons

Use a single consistent SVG icon library or professionally coordinated icon system.

Do not use emoji as interface icons.

Icons should represent meaningful actions or information, not merely decorate content.

## 6. Prevent AI-Slop from Returning

These restrictions apply to all subsequent design changes within this prototype.

Before adding any visual element, evaluate:

1. Does this element communicate meaningful information?
2. Does it improve navigation, comprehension, or interaction?
3. Is it consistent with the visual reference?
4. Does it contribute to the IKAPI Store identity?
5. Would the design still work or improve if this element were removed?

If the element is purely decorative and does not improve the design, remove it.

A visually appealing website does not need decorative badges on every section.

**Do not replace AI slop with a different style of AI slop.**

Specifically:

- No decorative badge → replacing it with a tiny uppercase eyebrow label.
- No colorful pill → replacing it with a glowing dot.
- No emoji → replacing it with random floating SVG icons.
- No excessive cards → replacing them with equally repetitive gradient panels.
- No empty space → filling it with meaningless marketing copy.

These are not acceptable fixes.
