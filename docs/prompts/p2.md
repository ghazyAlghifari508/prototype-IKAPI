# TASK: Perbaikan UI Katalog Buku IKAPI — Konsistensi Navigasi, Penyederhanaan Toolbar, Penghapusan Riwayat, dan Redesign Footer

## 1. Konteks dan tujuan

Perbaiki desain halaman Katalog Buku IKAPI Jawa Barat pada file:

`katalog_buku_desktop(1).html`

Gunakan referensi:

- `beranda_desktop.html` sebagai acuan konsistensi header dan footer.
- Screenshot halaman katalog yang diberikan pengguna.
- Screenshot toolbar filter dan footer lama.
- Referensi footer Gramedia yang sebelumnya diberikan.
- Keputusan redesign beranda IKAPI yang sudah disepakati.

**Fokus pekerjaan adalah perbaikan UI/UX secara visual, bukan redesign keseluruhan katalog atau audit kode yang tidak berkaitan.**

Saat ini halaman katalog memiliki tiga masalah utama:

1. Toolbar memuat filter tambahan yang redundan dengan sidebar.
2. Section "Terakhir Dilihat" berada di tempat yang tidak sesuai dengan fungsi halaman katalog.
3. Navbar dan footer belum mengikuti desain yang konsisten dengan beranda IKAPI.

Tujuan akhir adalah halaman katalog buku yang sederhana, konsisten, tidak terasa seperti template AI, dan memprioritaskan aktivitas pengguna dalam mencari serta memilih buku.

Jangan menambahkan komponen, section, dekorasi, atau copy baru tanpa kebutuhan yang jelas.

## 2. Perbaikan Pertama: Hapus Filter Redundan dari Toolbar

### Masalah saat ini

Di atas daftar buku terdapat toolbar yang memuat:

- `Semua Kategori ×`
- `E-Book Resmi ×`
- `Reset Filter`
- Input pencarian
- Grid/List view
- Dropdown pengurutan

Tiga elemen pertama membuat toolbar terlihat ramai dan tidak memberikan manfaat yang sebanding.

Kategori dan reset filter sudah tersedia di sidebar kiri.

Selain itu, label "E-Book Resmi" tidak perlu ditampilkan sebagai filter karena seluruh katalog IKAPI memang ditujukan untuk e-book.

### Perubahan wajib

**Hapus sepenuhnya dari toolbar:**

1. Chip `Semua Kategori ×`
2. Chip `E-Book Resmi ×`
3. Teks/tombol `Reset Filter` di sebelah chip.
4. Separator vertikal yang sebelumnya memisahkan chip dengan input pencarian.

Hapus juga ruang kosong, margin, padding, dan wrapper khusus yang menjadi tidak diperlukan setelah elemen tersebut dihilangkan.

Jangan sekadar menyembunyikan menggunakan CSS `display: none` apabila elemen sudah tidak diperlukan. Bersihkan markup yang berkaitan.

### Yang harus dipertahankan

- Input pencarian katalog.
- Dropdown pengurutan.
- Kontrol Grid/List yang saat ini tersedia.
- Sidebar filter kategori.
- Sidebar filter penerbit.
- Sidebar rentang harga.
- Tombol Reset di sidebar.

Jangan menghapus filter sidebar atau memindahkan seluruh filter ke toolbar.

### Wireframe sebelum

```

│                                                                  │
│ [Semua Kategori ×] [E-Book Resmi ×] Reset Filter │               │

│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### Wireframe sesudah

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│ [ 🔍 Cari berdasarkan judul atau penulis... ]  [▦ ▤] [Urutkan ▾]│
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### Panduan visual

- Input pencarian menggunakan ruang yang lebih luas.
- Kontrol grid/list dan sorting berada di sebelah kanan.
- Tinggi kontrol harus konsisten.
- Alignment horizontal rapi.
- Spacing tidak berlebihan.
- Background toolbar sederhana.
- Hindari menambahkan shadow besar atau gradient.
- Tidak perlu badge untuk menggantikan filter yang dihapus.
- Jangan menambahkan informasi baru seperti "Temukan buku terbaik", "Jelajahi koleksi pilihan", atau copy marketing lain.
- Toolbar cukup berisi kontrol yang dibutuhkan pengguna.

### Responsivitas

Desktop:

- Pencarian menempati area terbesar.
- Grid/List dan sorting berada di kanan.

Mobile:

- Input pencarian tetap mudah digunakan.
- Sorting dan kontrol tampilan boleh berpindah ke baris kedua apabila ruang tidak cukup.
- Tidak boleh ada horizontal overflow.
- Jangan mengecilkan ukuran input sampai sulit digunakan.

## 3. Perbaikan Kedua: Hapus Seluruh Section "Terakhir Dilihat"

### Masalah

Setelah grid produk dan pagination, halaman saat ini menampilkan section:

**Terakhir Dilihat**

Section ini berisi:

- Heading "Terakhir Dilihat".
- Deskripsi mengenai buku yang sebelumnya dibuka.
- Empat card buku.
- Informasi waktu terakhir dilihat.
- Kontrol "Riwayat Tersimpan (4)".
- Kontrol "Riwayat Kosong (Sembunyikan)".
- Empty state riwayat.

Penempatannya membuat halaman katalog kehilangan fokus.

Tujuan utama halaman katalog adalah membantu pengguna mencari dan menemukan buku melalui pencarian, filter, sorting, dan pagination.

Riwayat aktivitas pribadi merupakan konteks yang berbeda. Fitur tersebut tidak perlu dipaksakan berada di bawah seluruh hasil katalog.

### Keputusan

**Hapus seluruh section Terakhir Dilihat dari halaman katalog.**

Tidak perlu menggantinya dengan:

- Rekomendasi lainnya.
- Buku serupa.
- Buku populer.
- Banner promosi.
- Newsletter.
- Empty state.
- Card atau section tambahan apa pun.

Setelah pagination, halaman langsung berlanjut ke footer.

### Catatan teknis terbatas

Pada file lama terdapat section dengan ID:

`recently-viewed-section`

Juga terdapat fungsi:

`setRecentlyViewedState(hasHistory)`

Periksa dependensi yang terkait sebelum menghapus.

Bersihkan markup dan JavaScript yang khusus digunakan oleh section tersebut jika tidak digunakan di bagian lain.

Jangan membiarkan event listener mengakses elemen yang sudah dihapus.

Jangan menghapus atau mengubah sistem riwayat global di luar halaman katalog apabila sistem tersebut digunakan halaman lain.

Perubahan ini adalah **penghapusan fitur dari UI katalog**, bukan instruksi menghapus seluruh kemampuan penyimpanan riwayat pada aplikasi.

## 4. Perbaikan Ketiga: Konsistensi Navbar dengan Beranda

### Masalah

Tampilan navbar antarhalaman terasa tidak konsisten.

Website e-commerce harus mempunyai satu identitas navigasi yang sama. Pengguna tidak seharusnya merasa berpindah ke website berbeda ketika membuka katalog dari beranda.

### Acuan wajib

Gunakan **desain navbar beranda IKAPI versi terbaru** sebagai sumber referensi.

Periksa file beranda yang berlaku saat ini, bukan mengasumsikan prototype lama selalu merupakan desain final.

Samakan:

- Logo dan ukurannya.
- Tinggi header.
- Lebar container.
- Jarak antarelemen.
- Posisi search bar.
- Ikon keranjang.
- Indikator jumlah item.
- Elemen akun/login.
- Warna.
- Typography.
- Border atau shadow.
- Spacing navigasi.
- Responsive behavior.

Jangan membuat versi navbar yang hanya terlihat mirip.

**Konsistensi harus nyata dari segi layout, ukuran, dan gaya.**

### Hapus menu Kategori dari navbar utama

Navigasi utama yang diinginkan:

1. Katalog Buku
2. Agenda Literasi
3. Kabar &amp; Artikel
4. Komunitas Penerbit

Menu **Kategori** dihapus dari navigasi utama, termasuk pada halaman beranda jika masih ada.

Alasannya:

- Kategori sudah tersedia melalui bagian Jelajahi Kategori pada beranda.
- Kategori juga tersedia sebagai filter sidebar katalog.
- Tidak perlu menambah satu menu navigasi utama untuk akses yang sudah tersedia.

**Penting:** jangan menghapus kategori dari sidebar filter maupun bagian Jelajahi Kategori di beranda.

## 5. Perbaikan Keempat: Redesign Footer

### Masalah sekarang

Footer lama masih memiliki beberapa kelemahan:

- Warna ungu pucat terlalu dominan.
- Deskripsi organisasi terlalu panjang.
- Heading seperti "Katalog &amp; Eksplorasi" terasa kurang natural.
- Sejumlah tautan terlalu spesifik dan kurang terarah.
- Area informasi organisasi serta navigasi kurang seimbang.
- Footer terasa berbeda dengan pendekatan desain toko buku yang sedang dibangun.

### Acuan desain

Gunakan screenshot footer Gramedia yang diberikan pengguna sebagai referensi utama untuk:

- Pembagian kolom.
- Hierarki teks.
- Spacing.
- Penyusunan daftar tautan.
- Garis pemisah.
- Posisi copyright.
- Penempatan media sosial bila tersedia.

**Jangan menyalin seluruh teks, logo, maupun identitas Gramedia.**

Gunakan struktur visualnya, kemudian sesuaikan dengan kebutuhan IKAPI Jawa Barat.

- Background netral terang, mengikuti referensi Gramedia.
- Hindari background ungu yang memenuhi seluruh footer.
- Heading kolom sedikit lebih tebal dari link.
- Link menggunakan ukuran konsisten.
- Tidak perlu ikon di setiap link.
- Tidak perlu card dalam footer.
- Tidak perlu badge.
- Tidak perlu gradient.
- Tidak perlu dekorasi titik, glow, atau ilustrasi.

- Alamat kantor.
- Email.
- Nomor telepon.
- Akun media sosial.
- Legalitas.
- Halaman yang belum tersedia.

Jika data belum diverifikasi, jangan mengklaim data tersebut resmi.

Jangan membuat tautan palsu hanya agar footer terlihat penuh.

### Konsistensi dengan beranda

Footer katalog dan beranda harus identik secara desain dan struktur.

Jika footer beranda sudah diperbarui berdasarkan redesign sebelumnya, gunakan versi tersebut sebagai acuan, bukan membuat footer ketiga dengan desain baru.

Jika footer beranda belum diperbarui, terapkan rancangan final yang sama pada kedua halaman.

Jangan menambahkan footer khusus untuk katalog.

## 8. Quality Requirements: Anti-AI-Slop

Seluruh perubahan harus terasa natural untuk website e-commerce.

Hindari:

- Badge berwarna mencolok tanpa fungsi.
- Random dots.
- Glow.
- Gradients dekoratif.
- Card tambahan yang tidak diperlukan.
- Ikon dekoratif di heading.
- Copy marketing generik.
- Slogan panjang.
- Animasi berlebihan.
- Hover scale besar.
- Shadow mencolok.
- Garis aksen dekoratif.
- Label uppercase kecil di atas setiap heading.
- Komponen yang terlihat modern tetapi memperburuk keterbacaan.

Gunakan:

- Layout sederhana.
- Spacing konsisten.
- Tipografi yang jelas.
- Warna merek secara proporsional.
- Navigasi yang mudah dikenali.
- Informasi yang relevan.
- Elemen interaktif dengan fungsi yang jelas.

Jangan menganggap setiap area kosong harus diisi dengan gambar, card, atau teks.

Whitespace adalah bagian dari desain.

## 9. Urutan Pengerjaan

Kerjakan sesuai urutan berikut.

### Langkah 1 — Pemeriksaan

Baca HTML katalog dan beranda.

Bandingkan visual header dan footer yang berlaku saat ini.

Identifikasi elemen yang perlu dihapus serta styling yang akan terdampak.

### Langkah 2 — Toolbar

Hapus tiga elemen redundan.

Rapikan susunan pencarian, Grid/List, dan pengurutan.

Pastikan tidak meninggalkan ruang kosong.

### Langkah 3 — Terakhir Dilihat

Hapus seluruh section dan kontrol simulasi riwayat.

Bersihkan JavaScript khusus section tersebut dengan aman.

Pastikan pagination langsung diikuti area footer tanpa section pengganti.

### Langkah 4 — Navbar

Samakan navbar dengan beranda.

Hapus menu Kategori dari navigasi utama kedua halaman.

Pastikan active state dan tampilan responsif konsisten.

### Langkah 5 — Footer

Gunakan struktur referensi Gramedia dan keputusan redesign beranda.

Sederhanakan copy dan tautan.

Samakan footer di beranda dan katalog.

### Langkah 6 — Final QA

Periksa hasil visual di desktop dan mobile.

Pastikan perubahan sesuai screenshot referensi dan tidak menghasilkan desain generik baru.

Periksa fungsi yang berkaitan dengan elemen yang diubah.

Jika browser atau preview tersedia, ambil screenshot final untuk membandingkan dengan desain sebelumnya.

Jangan melakukan perubahan di luar scope selama QA.

## 10. Acceptance Criteria

Pekerjaan dianggap selesai jika:

- Chip "Semua Kategori" di toolbar dihapus.
- Chip "E-Book Resmi" di toolbar dihapus.
- Tombol "Reset Filter" di toolbar dihapus.
- Separator dan spacing yang tidak diperlukan sudah dibersihkan.
- Input pencarian tetap terlihat rapi.
- Grid/List dan dropdown sorting tidak rusak.
- Filter sidebar tetap tersedia.
- Tombol Reset di sidebar tetap dipertahankan.
- Seluruh section "Terakhir Dilihat" dihapus.
- Tombol simulasi riwayat dihapus.
- JavaScript khusus section riwayat dibersihkan tanpa merusak fungsi lain.
- Pagination langsung diikuti footer.
- Navbar katalog dan beranda memiliki desain yang sama.
- Menu Kategori di navbar utama dihapus dari kedua halaman.
- Active state Katalog Buku benar.
- Footer katalog menggunakan rancangan yang sama dengan beranda.
- Copy footer lama yang tidak relevan sudah dihapus.
- Footer mengikuti struktur visual referensi Gramedia.
- Tidak ada tautan atau informasi organisasi palsu yang ditambahkan.
- Tidak ada badge dekoratif, gradient, glow, atau komponen AI generik baru.
- Tampilan mobile tetap rapi.
- Tidak ada horizontal overflow yang disebabkan perubahan.
- Tidak ada JavaScript error akibat elemen yang dihapus.
- Grid buku, filter sidebar, dan pagination tidak mengalami regresi.
- Tidak ada perubahan besar pada bagian yang berada di luar scope.
