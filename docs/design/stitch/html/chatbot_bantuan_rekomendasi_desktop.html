Catatan: Semua e-book dilindungi hak cipta digital (DRM) dan otomatis terbuka di Web Reader segera setelah transaksi terverifikasi.
Bagaimana alur pembayaran QRIS dan cara membuka buku di Web Reader?
IK Panduan Transaksi IKAPI

Alur Pembelian & Sinkronisasi Reader:

  1. Checkout & QRIS: Pembayaran diproses instan melalui gerbang Midtrans Snap (QRIS, VA Bank Mandiri/BCA/BNI).
  2. Verifikasi Otomatis: Tidak perlu konfirmasi manual via WhatsApp. Status pembayaran langsung beralih ke Lunas dalam hitungan detik.
  3. Buka Web Reader: Akses menu "Perpustakaan Saya" di akun Anda, lalu klik tombol Mulai Membaca.
Kompatibilitas Perangkat: Web Reader dapat dibuka langsung lewat Safari, Chrome, atau Firefox tanpa instalasi aplikasi tambahan baik di PC, tablet, maupun ponsel.
